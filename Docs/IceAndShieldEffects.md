# Ледяное копьё и каменная кожа

В `Assets/GeneratedWizard/IceShard.prefab` установлен вложенный `Crystal effect blue`. Его локальный поворот по X равен 90°: длинная ось кристалла направлена вдоль полёта снаряда, по Z. Старые частицы, ядро, след и VFX Graph отключены. Кристалл появляется сразу, без медленной анимации роста. Сетевой корень, коллайдер, 22 урона, скорость 24, время жизни 4 секунды и замедление сохранены.

Для каменной кожи создан `Assets/GeneratedWizard/StoneSkinShield.prefab` на основе `Magic shield gray`, ссылка записана в `StoneSkin.asset`. Основные слои рассчитаны на 5 секунд — длительность способности. `StoneSkinShieldVisual` на префабе игрока создаёт эффект на клиентах, следит за событием синхронизированного запаса защиты и удаляет эффект при обнулении щита. Поэтому защита на 50 урона может визуально закончиться раньше пяти секунд при разрушении, смерти или удалении игрока. Поздно подключившийся клиент получает визуальное состояние из текущего значения щита. Прежняя короткая вспышка получения защиты отключена.

Материалы адаптированы для URP в `Assets/GeneratedWizard/ImportedSpellMaterials`. Исходные префабы пакета не изменены. Дополнительные источники света и тени отключены.

Проверка: `Tools → Wizard War → Validate ice and shield effects`. Превью и резервные копии находятся в `Logs/IceAndShieldEffects`. Визуальную проверку в бою и на нескольких клиентах пользователь выполняет самостоятельно; все клиенты должны использовать обновлённый префаб игрока.
