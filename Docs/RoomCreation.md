# Создание комнаты и сервер

Кнопка, вызывающая MainMenuUI.CreateRoom, открывает диалог Create Room UI, сохранённый в Menu.unity. В нём можно ввести название (до 32 символов), отменить действие или нажать «Создать». Пустое имя не допускается. Пробелы по краям убираются; последнее название запоминается.

MainMenuUI.ConfirmCreateRoom передаёт название RoomNetworkDiscovery до StartHost. Это название отправляется другим игрокам в локальной сети и отображается в списке комнат.

Create Room UI — отдельный корневой Canvas сцены Menu с высоким Sorting Order. Размеры, цвета, поле ввода и кнопки редактируются прямо в Editor. Он не создаётся при запуске игры. Существующие кнопки книги, кастомизации и игры сохранены.

MainMenuUI.CreateServer запускает StartServer в текущем приложении и объявляет сервер через Discovery. Локальный клиент и персонаж не создаются. Для игры самому вместе с подключившимися игроками используется CreateRoom → StartHost.

Никнейм в TAB берётся из PlayerName в дочернем объекте Entity, в том числе при скрытом над своим персонажем Canvas.
