# Освещение арены

Первый пресет: тёплое солнце, прохладный заполняющий свет в тенях, мягкие тени, слабая дымка вдали. Bloom подсвечивает яркие огненные эффекты; золотая отделка и кристалл посоха получили более выраженный блеск.

Настройка в Unity:
- SampleScene → Directional Light: цвет, Intensity и поворот солнца.
- SampleScene → Global Volume → профиль ArenaLook: Bloom → Intensity регулирует свечение, Threshold — порог яркости. Стартовая интенсивность 0.22.
- Assets/Settings/ArenaLighting/ArenaSky.mat: небо.
- Window → Rendering → Lighting → Environment: цвета заполнения теней и туман.
- Фаерболл использует отдельные копии материалов в Assets/Settings/ArenaLighting, чтобы правки не влияли на другие эффекты.

Пресет не добавляет динамические источники света каждому снаряду. Motion Blur, размытие глубины и блики объектива не включены. Внешний вид и FPS во время массового каста проверяет пользователь в игре.

Меню Wizard → Lighting → Apply arena lighting to saved arena повторно применяет исходные значения пресета. Для ручной подстройки меняйте сцену/профиль напрямую, без повторного применения.
